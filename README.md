# Sapphire Sentry

Full-colour Python 3 neon tower-defense lite arcade for ElbowOS.

Defend the cyan vault base from cascading orange crystal invaders.
Click to place magenta-gold turrets that auto-fire cyan shots.
Score by destroying enemies before they reach the base.

## Play
```
pip install -r requirements.txt
python3 sapphire_sentry.py --play
```

## Record a 9:16 reel
```
python3 sapphire_sentry.py --record
```
